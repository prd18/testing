## Cheatsheet Contents

The cheatsheet covers 15 major topic areas:

1. **Data Types** — integers, floats, booleans, None, type checking and casting
2. **Strings** — all common string methods, f-strings, multi-line strings, slicing
3. **Lists** — access, modify, sort, copy, membership, concatenation
4. **Tuples** — access, unpacking, star unpacking, converting to/from list
5. **Dictionaries** — access, update, iteration, merging (Python 3.9+), `fromkeys`
6. **Sets** — add/remove, union, intersection, difference, symmetric difference
7. **Control Flow** — if/elif/else, ternary, for/while loops, break/continue, match (Python 3.10+)
8. **Functions** — positional, default, `*args`, `**kwargs`, type hints, lambdas, docstrings
9. **Classes & OOP** — class/instance attributes, inheritance, `super()`, `@property`, `@staticmethod`, `@classmethod`, dunder methods
10. **File I/O** — read, write, append, file modes, `pathlib.Path`
11. **Error Handling** — try/except/else/finally, raising, re-raising, custom exceptions, context managers
12. **Comprehensions** — list, dict, set, generator expressions, nested comprehensions
13. **Modules & Imports** — standard library highlights: `os`, `sys`, `json`, `math`, `random`, `datetime`, `pathlib`, `typing`
14. **Built-in Functions** — iteration helpers, aggregation, type conversion, introspection, I/O
15. **Quick Tips** — walrus operator, swap, chained comparisons, `Counter`, `defaultdict`, `namedtuple`, decorators
